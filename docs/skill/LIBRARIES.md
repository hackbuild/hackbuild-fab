# hackbuild bench libraries 0.1.0

Generated by tools/skill-kit/reference.mjs from the built files and types. Do not edit by hand; `npm run skill:reference` rewrites it and a test fails when it is stale. Release tag `lib-v0.1.0`, base `https://cdn.jsdelivr.net/gh/hackbuild/hackbuild-fab@lib-v0.1.0/`.

A bench page loads these libraries and writes only what belongs to its design: its chase, its bench declaration, its build. It carries no mesh kernel, no 3MF writer and no bench shell of its own. `node tools/skill-kit/check-page.mjs <page.html>` refuses a page that does.

Each IIFE has a sidecar `<short>.sources.json` beside it with the sha256 of the script text and the bare imports it reads. A bake inlines the script under a banner comment `/* <name> <version>, iife build, global <Global> */`; `check-page` reads that banner and the sidecar sha256.

A page opened over http can call the shell's "save offline" action (print panel): it fetches these classic scripts and writes one file that opens from file:// with no network.

## createBench

`createBench(options)` from `@hackbuild/bench` returns a controller. `controller.mount(el)` draws the shell; `controller.core` is the headless bench core. Effects outside the mount element are opt-in and default off.

```ts
/** What every bench needs, whether a host app or a baked page mounts it. */
export interface BenchOptions {
    readonly chase: Chase;
    readonly bench: Bench;
    /** The library build (pageBench); without one the stage stays empty and the status reads NO_BUILD. */
    readonly build?: BenchBuild;
    /** Export writers by kind beside json (pageBench); a declared kind with none refuses with NOT_IN_BAKE. */
    readonly writers?: Readonly<Record<string, BenchWriter>>;
    /** Mount the WebGL stage; default true. */
    readonly stage?: boolean;
    /** The ContactFn the bench's DriveDecl.contact names, from the design's build.ts; none leaves the pad unable to drive. */
    readonly contact?: ContactFn;
    /** An hbf draft page (pageBench sets it from the page build): the status strip shows the draft banner. */
    readonly draft?: boolean;
    /** The draft's one inline widget (widget.ts), drawn beside the banner; only a draft page carries one. */
    readonly widget?: DraftWidget;
}

/**
 * createBench options. Every effect on the page outside the mount element is
 * an opt-in and defaults off, so a host app can hold several benches.
 */
export interface CreateBenchOptions extends BenchOptions {
    /**
     * The Pinia the shell store mirrors the core into. A host app passes the
     * one it installs so the bench's store sits beside its own; default, the
     * controller makes its own. Two controllers that share one Pinia share
     * the shell store, so give each its own.
     */
    readonly pinia?: Pinia;
    /** Define `BENCH` on globalThis (BenchHook); default false. */
    readonly hook?: boolean;
    /**
     * Boot the manifold kernel from the classic scripts a bake wrote (the
     * manifold factory, its base64 wasm and JSZip on globalThis); default false.
     * Without it the caller passes `manifold`, or an instance already adopted
     * through adoptManifold in @hackbuild/geom is used.
     */
    readonly globals?: boolean;
    /** A manifold module the caller booted (setup() called); adopted before the first build. Ignored when `globals` is set. */
    readonly manifold?: BootedManifold;
    /** Open a share link from location.hash after boot; default false. */
    readonly hash?: boolean;
    /** Write the kernel status to html data-kernel after a kernel boot; default false. */
    readonly dataset?: boolean;
    /**
     * The design folder a CDN page loaded its design from (build:design output).
     * With it the export panel can save the page offline: one file with the
     * classic library builds and the design inlined. Without it, or on a page
     * that is already offline, the action is disabled and says why.
     */
    readonly offline?: OfflineOptions;
}

/** One export a page writes from a build, beside the design json the bench writes itself. */
export interface BenchWriter {
    /** The file name a download takes. */
    readonly file: string;
    readonly media: string;
    /** The bytes, and the checks run on them; a blocking fail among them refuses the export. */
    write(result: BuildResult<ViewPart, BenchReport>): Promise<{
        readonly bytes: Uint8Array | string;
        readonly results: readonly CheckResult[];
    }>;
}
```

The `build` option is `(state) => Promise<{ part: ViewPart, report, buildHash, warnings? }>`. A page with no build opens with its rail, undo and design files working and an empty stage. A design's build comes from its page build (`npm run build:design` or `hbf adopt`), never from a mesh kernel typed into the page.

## The BENCH hook

`createBench({ hook: true })` defines `BENCH` on globalThis. A page without it is refused by check-page.

```ts
export interface BenchHook {
    /** True once the first build finished and the hook is safe to drive. */
    readonly ready: boolean;
    /**
     * Getter returns the design; setter replaces it and rebuilds. A value
     * outside a declared range or option set is clamped to the range (an
     * enum or slot falls back to its default) and each clamp appends a log
     * line naming field, value and range within 100 ms (G-10, P-07):
     * `clamp body.w: 40 outside 12 to 30, set 30`. A write never hangs.
     */
    state: unknown;
    /** The last built model. */
    readonly model: unknown;
    /** Increments on every commit, count. */
    readonly rev: number;
    /** rev of the last completed build, count. */
    readonly built: number;
    /** Building, or auto-build pending with built !== rev. A thrown build clears it (G-11). */
    readonly busy: boolean;
    /** Build hash of the last completed build, null before the first. */
    readonly buildHash: string | null;
    /**
     * Message of the last thrown build, null after a good build (P-07, G-11).
     * A non-Error throw is stringified, never "undefined". While set, the
     * stage keeps the last good mesh and the status strip shows an error chip
     * with this text.
     */
    readonly error: string | null;
    readonly log: string[];
    /**
     * Resolves when ready && !busy && built === rev. Rejects with
     * `build failed: <error>` when the build for the current rev throws, and
     * with `not settled after <timeoutMs> ms` on timeout. timeoutMs in ms.
     */
    settled(timeoutMs?: number): Promise<void>;
    /**
     * Merge onto a fresh blank, drop retired keys, clamp to declared ranges
     * with one log line per clamp (as the state setter), then commit. Text
     * that is not a design for this bench leaves the design untouched, sets
     * `error` and logs the reason; it never throws to the page or opens an
     * alert (G-37).
     */
    loadDesign(json: string): void;
    designJson(): string;
    ensureMesh(): Promise<void>;
    commit(): void;
    /**
     * Drive pad stimulus: hold a key, slide a pot, tilt a stick. value is a
     * boolean for hold, a number in the target's unit for slide (mm) or a
     * one-axis tilt (degrees), and { tiltDeg, phiDeg } for a stick (P-06).
     * Calls the same ContactFn as the pad, the 3D pose and the readout
     * (DriveDecl.contact, G-20). The stimulus stays applied until release.
     */
    drive(target: string, value: DriveStimulus): Promise<DriveReadoutRecord>;
    /** Release one held target, or every held target when none is named; resolves once the pad is idle (P-06). */
    release(target?: string): Promise<void>;
    /**
     * Base64 bytes of a declared export; kind resolved through EXPORT_ALIASES.
     * Awaits ensureMesh first (G-46). A kind the bench does not declare
     * rejects with an Error whose message is UNKNOWN_EXPORT_KIND followed by
     * the kind, never a TypeError (G-51).
     */
    exportBytes(kind: string): Promise<string>;
    /** Design extras: firmware, wiringSvg, printCard, setTilt. */
    readonly verbs?: Readonly<Record<string, (...args: readonly unknown[]) => unknown>>;
}
```

## The art document and its layer kinds

An `art` param whose `accepts` includes `layers` mounts the art board: the face canvas takes the stage while the step is active, the layer list and fields stay in the rail, and a stage toggle switches between board and model. The param value is `{ uri, kind: "layers", doc }`; every edit writes a new uri.

- schema `hbf.art`, version 1
- faces: `front`, `back`
- layer kinds: `text`, `shape`, `logo`, `scope`, `circuit`, `path`, `image`, `relief`
- cuts: `none`, `through`, `pocket`
- base layer defaults: `{"dx":0,"dy":0,"rot":0,"slot":1,"slot2":2,"cut":"none","depth":1.2,"mute":false}`
- kind defaults: `{"text":{"text":"","font":"plexb","size":4,"ls":0,"arc":0,"splitGap":0.6},"shape":{"shape":"ring","w":20,"h":20,"t":1.2,"n":6},"logo":{"brand":"hb","w":30},"scope":{"a":3,"b":2,"phase":90,"w":30,"h":22,"t":0.9},"circuit":{"seed":7,"w":34,"h":40,"pitch":2.4,"tw":0.8,"pad":2.2,"drill":0.7,"density":1,"clip":"ellipse"},"path":{"d":"","bx":0,"by":0,"bw":10,"bh":10,"w":24},"image":{"src":"","mode":"mono","w":24,"thr":0.5,"invert":false},"relief":{"src":"","depthSrc":"","source":"depth","model":"onnx-community/depth-anything-v2-small","device":"auto","w":30,"height":2.4,"base":0.24,"bgcut":0.25,"gamma":1,"smooth":0.3,"detail":0.15,"roll":1.2,"inset":0.6,"thr":0.5,"invert":false,"mode":"smooth","split":1}}`

## Export path and self-check

The export kinds a chase declares (`json`, `3mf`, `stl`, `card`) write through `BenchOptions.writers`; `pageBench(pageOf(globals.page))` supplies the 3mf, stl and card writers of a design page build, which run the build and every check and refuse a blocking fail with the export gate's line. A fabrication export also needs the host's approval; no argument opens that gate.

Before the shell hands a 3mf to a download it runs `assertExportable("3mf", bytes)` from `@hackbuild/bench-core`. The rules, ported from tools/py/validate_3mf.py:

- `3mf-zip`: the package is a readable zip with at least one .model part.
- `3mf-id`: object ids are unique in each model part and every item and component reference resolves (CHK-3MF-06).
- `3mf-uuid`: every `p:UUID` is unique across the package.
- `3mf-name`: object names are non-empty, carry no unresolved token and are unique (CHK-ART-01).
- `3mf-manifold`: every mesh has two faces per undirected edge, one use of each directed edge and positive signed volume (CHK-PRT-01).

A failing rule refuses the download and the log names it. The same functions are exported for a page's own use:

```ts
export type SelfCheckRule = "3mf-zip" | "3mf-id" | "3mf-uuid" | "3mf-name" | "3mf-manifold";
```
