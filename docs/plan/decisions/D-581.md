### D-581 The hbf plugin commits only the tracked forge references

| field | value |
|---|---|
| Status | decided |
| Decision | Taken by the agent under owner delegation on 2026-10-20. tools/plugin/build.mjs copies into plugin/hbf/skills/hbf/references/ only the files of the absorbed forge skills (print-forge, board-forge) that git tracks under knowledge/references, each with one provenance line and a generated INDEX.md. The board-forge folder and the forge SKILL.md copies, which .gitignore keeps in the owner archive (D-576), are built into references/archive/ only where they are on disk, and plugin/hbf/.gitignore keeps that folder out of git. The copies are generated from an in-repo source, so they carry no lineage row of their own. |
| Rationale | Committing the archive copies would reverse the public-tree exclusion D-576 kept, and two of them carry local absolute paths; a plugin cannot reference files outside its root, so the owner's local plugin still holds the repaired board-forge, datasheet and diagram text. |
