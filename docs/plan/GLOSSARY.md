# Glossary

Version 4, 2026-10-04. Part of the hackbuild-fab plan set (PLAN.md v4).
At M-1 this file copies to `docs/plan/GLOSSARY.md` (D-162).

Every term the plan set uses with a fixed meaning, alphabetical, ignoring
case and leading punctuation. Each entry gives the meaning, where the term
is defined (decision id, spec file, plan document) and any retired
synonym. Spec paths are relative to the hackbuild-fab root after M-1
(`spec/ids.ts` is `fab-knowledge/plan/spec/ids.ts` until then). Working
names are marked "(working name)" and stay unconfirmed until the owner
answers D-012. Numbers carry a qualifier per D-007. Counts are as of
2026-10-04 and are generated by `tools/counts.mjs` from M-1 onward.

Retired and banned names, and the slug collisions of D-015, are in the
two tables at the end.

---

## A

**arch.apply**
The command that places an archetype on a face of any part and writes the
placement into `chase.applied` (`AppliedArchetype` in `spec/chase.ts`).
It is a CLI command at M06 and becomes a mouse gesture at M15 that calls
the same command; the MCP tool is `arch_apply`. Defined in D-014, D-106,
D-107, D-132; CANONS.md, AGENT-SURFACE.md.

**archetype**
A proven parametric circuit entry in the `archetypes` registry: channels,
senses, emitted feature kinds, read model, resistance computed at load
from profile resistivity (D-098), tier and a reference. 29 are seeded.
Retired synonym: circuits (the old canon package name, one letter from
"circuit"). Defined in D-014, D-095, D-097; `ArchetypeDef` in
`spec/canon.ts`; CANONS.md.

**artifactHash**
sha256 over the sorted list of (entry name, sha256 of the uncompressed
entry bytes) of an export, with date metadata normalised. It is the hash
the js and py 3MF writers must agree on; byte identity across writers is
outside the requirement. Defined in D-052 (correction C-08); ARCHITECTURE.md,
TESTING.md.

**assertion**
A declared relation the build must satisfy, checked like any other
declaration: `apart`, `volumeParity`, `mirrorOnFlip`, `capture`. A capture
assertion passes when interference exceeds a declared floor (DERRICK
33.4 mm3, measured on the legacy build). Defined in D-063, D-074;
`Assertion` in `spec/part-ir.ts`.

## B

**bake**
Producing one offline single-file HTML bench from a design: a per-design
asset manifest, deterministic sha256, at most 16 MB, zero network at load,
no blob or module Workers under `file://`. The seed is pip-controller
`tools/build_bench.py` plus COTTER baker features. Defined in D-129;
UI.md, TESTING.md.

**bench**
Internal word for the layout a chase renders into. User copy uses the
tool name (PIP, KNUCKLE), never "bench" as a generic noun; the title
suffix `NAME.bench` survives. Not to be confused with BENCH, the
catalogue. Defined in UI.md; `synthesis/aesthetic-voice-ux-bible.md`
section 11.

**BENCH**
The catalogue of hack.build tools: 157 tools in 16 groups, 153 placeable
(counted from the KB copy
`fab-knowledge:evidence/x/downloads/dl-boards-tools/hackbuild-tools-2/MANIFEST.json`).
It grew on 2026-08-06 through 90, 144 and 157 tools: `hackbuild-tools.zip`
(90) and `hackbuild-tools (1).zip` (144) sit in
`fab-knowledge:evidence/x/downloads/dl-boards-tools/hackbuild-tools/`, and
the 157 zip, `hackbuild-tools-2/hackbuild-tools (2).zip`, holds 334
entries.
M16 unions it with `registry/tools.json` into one filterable dataset.
BLOCKS is never called a bench. Defined in D-158; REPOS.md,
milestones/M16-knowledge-registry.md.

**BenchHook**
The object every baked bench exposes on `globalThis` as `BENCH` for tests
and agents, frozen in PIP's getter style: `ready`, `state`, `model`, `rev`,
`built`, `busy`, `buildHash`, `log`, `settled()`, `loadDesign`,
`designJson`, `ensureMesh`, `commit`, `drive`, `exportBytes`, verbs. A
bench without it is not done, because smoke cannot drive it. Defined in
D-128; `spec/hook.ts`; UI.md section 13.

**bleed**
Per (machine, material pair) growth of printed traces, applied once at
emit, coupons included. Default 0 until a coupon measures it. Published
PIP draws 1.4 mm traces with no bleed; the 0.15 mm bleed, 1.25 mm drawn
and 0.75 mm gap belong to the HAFT branch after the PIP commit
(`haft (7).html`, 2026-09-18 21:03, onward), which is unpublished.
Defined in D-084 (correction C-06); PROFILE.md. Evidence:
`fab-knowledge:evidence/x/downloads/dl-pip-latest/haft/haft (7).html`.

**body**
One material region of a part: `{id, mesh, material, slot, role}`. A part
holds `bodies[]` and the solid is their union; features may name a body.
Roles in partition priority: flex-conductor, flex, conductor, art, body.
Defined in D-047, D-048; `spec/part-ir.ts`.

**BOSS**
The name of BLOCKS bench v1 and the source of the 50 kohm pullup sim with
a single 0.5 VIO threshold. Kept only to reproduce the BOSS result (D-076,
D-077); retired as a tool name (became BLOCKS). Defined in D-076, D-077,
D-087.

**build hash**
Hash of the RFC 8785 canonical `BuildInputs` (defHash, paramsHash,
profileHash, registryHash, kernelVersion, engines, adapter, seed,
sourceDateEpoch, licences). Two builds with one hash are the same build.
Defined in D-051; `BuildInputs` in `spec/registry.ts`; ARCHITECTURE.md.

**build.ts**
The design's computation: params in, `PartDraft` or `AssemblyDraft` out.
It holds no declarations; those live in the chase (standard rule 1).
Defined in D-047; `BuildFn` in `spec/build.ts`.

**buried stack**
The skin, trace layer and isolation layers that carry printed traces
inside a part. PIP defaults: skin 0.72, trace layer 0.72, isolation 0.96,
PETG over layer 2 1.68 on the 0.72 floor, trace width 1.4, net-to-net
floor 0.60 mm (computed off the PIP model). The v3 values 0.48 insulation,
0.48 over L2 and 0.3 net floor are retired. Defined in D-085; PROFILE.md.

## C

**CHASE (working name)**
The typed design document: a TypeScript module written with `defineChase`
and type-checked against `@hackbuild/spec`, with schema version 2,
migrations and deep normalise on load. It holds declarations; computation
lives in build.ts. Defined in D-012 (owner), D-131, D-132;
`spec/chase.ts`; PLAN.md section 13.

**check**
A registry entry that proves a declaration against Part IR and returns
evidence as a `CheckResult`. Each check carries a semver version, an
origin record naming the failure that produced it, and a legal-value
kind. 86 are seeded (77 block, 9 warn; counts.json wins). Defined in D-064 to D-067;
`CheckDef` in `spec/checks.ts`; CHECKS.md.

**CheckResult**
The shape every check returns: `id`, `version`, `verdict`, `severity`,
`target`, `measured`, `legal`, `constraint`, `origin`
(`hbf://check/<id>`), optional `fix` and `extra`. A result without
measured, legal, constraint and origin is a bug. Defined in D-064;
`spec/checks.ts`.

**click spring**
PIP's double-cosine PETG beam spring that snaps a conductive tip onto
pads. At PIP defaults (l 24, t 0.55, w 1.6, Q 2.0, E 1900, sw 3) the FE
model gives peak 2.527 N at 0.629 mm, drop 76.5 percent, contact 1.369 mm,
eStop 2.31 percent (computed, pip-controller `src/snapfe.js`). Its legal
Q window is CHK-KEY-04. Defined in D-071, D-096; CANONS.md, CHECKS.md.

**CommandResult**
The evidence every hbf command returns on every transport: verdicts,
`CommandError[]`, artifacts, `inputsHash`, `buildHash` and next calls.
Exit codes: pass 0, fail 1, input 2, gate unavailable 3, provenance 4,
repeat 5, internal 70. Defined in D-064, D-106, D-133;
`spec/commands.ts`, `spec/errors.ts`; AGENT-SURFACE.md.

**conformance corpus**
The 3MF files every writer and validator must pass or fail as expected:
the gold round trip, the 25 owner 3MFs, legacy bench exports and
known-bad fixtures (CASK empty plate, TENON undefined names, numeric
`overhang_fan_threshold`). Lives in `tools/corpus/3mf/` and moves with
hackbuild-3mf at M00 exit. Defined in D-027, D-068, D-069; TESTING.md.

**constraint dim**
A named dimension the interval solver bounds, such as `conductor.width`.
A `ParamField` may point at one through `constraintDim`, and enum options
then come from its legal values. Defined in D-072, D-125, D-132;
`spec/constraints.ts`, `spec/chase.ts`.

**coupon**
A printed test piece whose measured result writes a profile row. A person
enters the result; no model enters a coupon result. Coupons are the only
path to the measured tier. Defined in D-082, D-083, D-099; PROFILE.md.

**coverage rule**
Every feature kind, check, archetype, mechanism, kind and exporter has a
green reference. Enforced as a type (non-empty `reference` in
`FeatureKindDef`) and as a test derived from the registries at M11.
Defined in D-058, D-105; milestones/M11-reference.md.

## D

**derived count**
A number generated by `tools/counts.mjs`, never typed by hand. The CI
`derived` job fails on any `git status --porcelain` diff after
regeneration. A hand-typed count is a bug. Defined in D-010; Appendix B of
PLAN.md.

**design**
A shipped tool in `designs/<id>/` with `chase.ts`, `build.ts`, README and
a `legacy/` folder holding the original file with sha256 and lineage.
Graduated designs move to their own repo on the pip-controller template.
Defined in D-035, D-142.

**drive pad**
The stage overlay that stimulates a printed control and shows the
electrical readout (resistance, tau, wait, reject). PIP rows: touch 0.91
to 0.93 Mohm, keys 1.5 to 1.72 Mohm (computed). Defined in D-079; UI.md.

**drop**
Fractional force drop of a click spring after snap-through. CHK-KEY-04
requires drop at least `click.dropMin` (profile constant, default 0.5).
Defined in D-071.

## E

**E_UNSAT**
The error returned when floors exceed ceilings for one dimension; the
interval's legal value is null and the message names the binding bounds.
Example: at the PIP preset 500 ohm cm (inferred) the resistance floor for
a 62 mm trace is 53.8 mm (computed), so the result names 71.8 kohm at the
6.00 mm pitch ceiling. Defined in D-064, D-072 (correction C-01).

**eStop**
Strain at the stop of a click spring, in percent. CHK-KEY-04 caps it at
the in-plane strain limit (2.5 percent PETG, empirical). Defined in
D-071, D-073.

**expected/**
The golden folder of a reference: `build.json`, `report.json`,
`edit.json`, `artifacts.json`, and section renders. Only `hbf parity
--accept` writes the four JSON goldens; each section render has one named
writer run by a person (D-227); CI never overwrites it. Defined in D-105;
TESTING.md.

**export gate**
The approval every fabrication export passes after build and checks run.
MCP uses `input_required` with an HMAC `requestState`; the host asks on
`mcp__hbf__export_run`; the CLI needs a TTY and has no bypass flag. A
failing build is never offered for approval. Defined in D-109;
AGENT-SURFACE.md.

## F

**feature kind**
A generator, a non-empty check set, a fit class (function or `none`) and a
non-empty reference, enforced by type. 22 kinds from v3 plus eight
admitted (thread, bayonet, magnet, inlay, insert, spring, mount, relief);
names are camelCase. A kind is usable in a build from its admitting
milestone (`FEATURE_KIND_ADMISSION`); latch, coupon, pivot and pinInSlot
moved to a mechanism, a reference and joints. Defined in D-017, D-058,
D-059, D-177; `FeatureKindDef` in `spec/feature-kinds.ts`.

**ffc5p**
The Flashforge Creator 5 Pro machine profile: 4 extruders (vendor), 0.4
preset, with a 0.25 preset in `3d/coin/hsl.3mf`. Presets are dated, such
as `ffc5p_20260919`. Defined in D-101; PROFILE.md.

**filament template**
The 127 per-filament keys with per-slot values written into
`project_settings.config`, harvested from the gold round trip into
`packages/3mf/data/filament_template.json`. Keeps `filament_map`,
`filament_self_index`, `filament_extruder_variant`. The seed 97-key
template misses 37 gold keys and adds 7. Defined in D-159 (correction
C-07), D-150.

**fit class**
The tolerance band a joint uses, keyed by process pair and motion
(`FitClassId` in `spec/ids.ts`). Material-level loss wins over
machine-level loss. Defined in D-100; PROFILE.md.

**fix**
The one-param change and predicted verdict attached to a finding:
`{param (JSON pointer), set, predicts}`. Example: set `/clicky/Q` to 2.19,
predicts strain 2.50 percent and a pass (computed). Defined in D-064;
`Fix` in `spec/checks.ts`; CHECKS.md.

**Flash Studio**
The Flashforge slicer. Its round-trip save of a hackbuild 3MF is the gold
file every writer and CHK-3MF check must pass. Defined in D-068, D-159.

## G

**gold round trip**
`hackbuild-coin-nfc.3mf` saved by Flash Studio on 2026-08-19, conformance
fixture one. Source:
`fab-work-directory:benches/collar-coin/uploads/hackbuild-coin-nfc.3mf`;
repo copy `tools/corpus/3mf/gold/hackbuild-coin-nfc.3mf`. Defined in
D-068, D-159; milestones/M00-foundation.md.

## H

**hackbuild-ui**
The owner's published design system, `@virgilvox/hackbuild-ui` (0.2.0 on
npm, GUIDELINES v1.2). The bench layer goes upstream as package 0.3.0
carrying GUIDELINES v1.3. Retired synonym: theme (the handoff
`hbf/theme/tokens.css` names, now a retiring alias table). Defined in
D-116, D-117 (owner), D-118; UI.md.

**hbf (working name)**
The binary with CLI, MCP and HTTP transports over one command set, and
the MCP server key (`mcp__hbf__*`). Defined in D-012 (owner), D-106,
D-114; AGENT-SURFACE.md.

**hbf:// URI**
The content-addressed handle for builds, meshes, reports, artifacts and
static resources, resolved in `<workspace>/.hbf/store`. The MCP server
holds no state. Defined in D-050; ARCHITECTURE.md.

**house rules**
The attribution and language rules in RULES.md, enforced by
`.githooks/commit-msg`, `tools/lint-voice.mjs` and the CI `house-rules`
job. A milestone is green only with house-rules CI passing. Defined in
D-001 to D-004, D-157.

## I

**inferred**
The lowest provenance tier. Usable in sim; refused at fabrication export
with `E_PROVENANCE` (exit 4). Defined in D-083, D-102.

**inputsHash**
sha256 of a command's RFC 8785 canonical arguments; the loop-detection
key in `.hbf/calls.jsonl`. Defined in D-111; AGENT-SURFACE.md.

## K

**KernelId**
The one union naming kernels across `CheckDef.needs`, `Bound.kernel`,
`ChaseMeta.kernels` and `tools.json`; it includes `3mf`, `board`,
`inlay`. Defined in D-057; `spec/ids.ts`.

**kind**
One of six fixed chase layouts: single, composer, surface, board,
machine, catalog. A seventh needs a measured layout sharing nothing with
the six; slots are the valve. Defined in D-126; `ChaseKind` in
`spec/chase.ts`.

## L

**legal values**
What a measured value must satisfy: an interval, set, multiple or
boolean, carrying `nearest`. Defined in D-064; `LegalValues` in
`spec/checks.ts`.

**lineage**
The record of every copy of a kernel and the fixes each carries, with
sha256, in `lineage.json`. Ports start from the most refined copy.
Defined in D-156.

**lint-voice**
`tools/lint-voice.mjs`: blocks banned characters (dashes U+2012 to
U+2015, emoji ranges), wrong brand hex, exclamation marks in UI strings,
marketing adjectives, filler vocabulary and openers; warns on contrast
frames. Replaces lint-dashes. Defined in D-004; RULES.md.

## M

**M-1**
The housekeeping milestone that lands rules, enforcement, spec and
corrected seeds before any geometry code. Defined in D-157;
milestones/M-1-housekeeping.md.

**measured**
A value from a shop coupon with machine, coupon id, date and method. A
computed value never becomes measured by dropping its qualifier. Defined
in D-007, D-083, D-099.

**MeshRoute**
The union of mesh-making routes: raster, prism, stack, revolve (radial
fields), lathe, trace, csg, imported, brep. Each declares its
guarantees. Defined in D-053; `spec/ids.ts`.

**metric**
A build-time number in Part IR, such as a fit row, spring peak or drive
readout, hashed with the build so it cannot lag its geometry. Every
metric has a gate or is labelled informational. Defined in D-049, D-075;
`Metric` in `spec/part-ir.ts`.

**MRTR**
The MCP 2026-07-28 multi-round-trip request pattern behind
`input_required`. The export gate uses it with an integrity-protected,
bound, single-use `requestState`. Defined in D-108, D-109.

## N

**net-to-net**
The minimum gap between two conductive nets: 0.60 mm in PIP (computed
off the model). Defined in D-085.

## P

**Part IR**
The part as solid, bodies, typed features, frame, metrics, warnings and
build hash. Checks read Part IR only. Defined in D-047 to D-049;
`spec/part-ir.ts`; PLAN.md section 6.

**PartDraft**
What build.ts returns before the kernel generates geometry; the kernel
stages then run base, pre-union cutters, positives, post-union cutters,
partition, insets, frame emit, hash. Defined in D-047; `spec/build.ts`.

**parity triple**
The three tests a port passes: geometry matches, params round-trip, one
edit gives the expected delta. Defined in D-152; TESTING.md.

**per-MCU pin table**
Pullup range and VIL and VIH per microcontroller, as catalog rows with
provenance. RP2040 (Pico inherits): pullup 50 to 80 kohm, VIL max 0.8 V,
VIH min 2.0 V at 3.3 V (vendor). ESP32-C3: pullup 45 kohm typical, VIL
max 0.825 V, VIH min 2.475 V (vendor). Replaces the BOSS 0.5 VIO
threshold and the 0.3 to 0.7 VIO UI hint. Defined in D-076 (correction
C-02); `McuPinSpec` in `spec/circuit.ts`.

**pink budget**
One focal pink element per view, counted in smoke. Defined in D-125;
UI.md.

**PIP (was HAFT)**
The published print-in-place controller, `hackbuild/pip-controller`
(b137deb, 2026-09-19 UTC, MIT), canonical over `x/haft`. hackbuild-fab
never edits pip-controller and never writes the old name into it.
Retired synonym: HAFT. Defined in D-013, D-080; REPOS.md.

**profile**
The package and data holding every number with provenance: materials,
resistivity, strain, machines, fits, constants. Only coupons entered by a
person write to it. Defined in D-081, D-099 to D-101; PROFILE.md.

**provenance tier**
verified, measured, vendor, community, inferred (highest first; default
pending owner). Every data row carries one. Defined in D-083 (owner);
`Tier` in `spec/ids.ts`.

**PSLIP**
The mixed printed and cut fit class at 0.15 mm. Replaces the dropped
PSLIDE. Defined in D-100.

## Q

**Q**
Rise ratio of a click spring: rise over beam thickness. At PIP defaults
the FE model snaps from Q 1.2 and is bistable from Q 2.32 (computed).
Defined in D-071 (correction C-04).

**qualifier**
measured, computed, vendor, inferred or unknown, on every number in
prose, UI, print cards and check messages. Defined in D-007;
`Qualifier` in `spec/ids.ts`.

## R

**read model**
How a port is read: pullup, charge-release, adc, ratiometric,
column-scan, ladder, each with per-net tau, wait and reject. Waits come
from a coupon; computed waits are qualified. Defined in D-078;
`ReadModel` in `spec/circuit.ts`.

**reference**
The smallest worked design proving one idea, kept green:
`reference/<area>/<id>/` with chase.ts, build.ts, README.md, expected/
and a `covers` list. Written in the milestone that admits the item.
Defined in D-105; PLAN.md section 11.

**requestState**
HMAC-SHA256-protected opaque state an MCP gate round trip carries,
binding command, args digest, build hash, a 10-minute expiry and a
single-use nonce (`.hbf/gate-used.jsonl`). Defined in D-109.

**rule zero**
No AI or LLM attribution anywhere: commits, trailers, package.json,
comments, docs, changelogs, PR bodies, exported file metadata, UI and
About panel. Defined in D-001, D-002; RULES.md.

## S

**SOURCE_DATE_EPOCH**
The fixed time every writer stamps for reproducible bytes: CreationDate,
ModificationDate and UTC zip mtimes. Recorded in BuildInputs as
`sourceDateEpoch`. Defined in D-051, D-052.

**STYLUS (working name, was FEELER)**
The printed sensor design built from archetypes, starting from THINPOT's
22 printed archetype candidates. Retired synonym: FEELER. Defined in
D-012 (owner), D-164.

## T

**toolset profile**
A subset of the 19 MCP tools a host loads: `all` (19), `query,prove`
(10), `sweep` (5). Defined in D-107; `TOOLSET_PROFILES` in
`spec/commands.ts`; AGENT-SURFACE.md.

## U

**undefined band**
The voltage range between a pin's VIL and VIH where a read is not
defined; `circuit.solve` reports `UNDEFINED`. Defined in D-076, D-077;
`PinState` in `spec/circuit.ts`.

## V

**verified block**
The README section "What is verified, and what is not", with four lists:
verified on this machine with date, measured on a printed body, checked
by machine on geometry, not verified by anything. Required in every
design README, reference README and published post. Defined in D-008;
DOCS.md.
