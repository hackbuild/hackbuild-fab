## What this milestone proves

Before M04 the checks exist as seed rows and as the handful of
implementations earlier exits needed (M00: CHK-PRT-01, CHK-PRT-03,
CHK-3MF-04 and the 3MF validator mirror; M01: the constraints behind
CHK-KEY-04 and CHK-NET-05; M02: the sweep modes; M03: CHK-INL-01 to 04).
M04 turns all 86 seeded checks into typed `CheckDef` registry entries with
a version, an origin record, a legal-value kind and, where one param drives
the measured value, `drivenBy`. A check whose kernel or target does not
exist yet is registered and reports skip with the milestone that lands it,
so the registry is complete on day one and honest about what runs.

The second contract is the build hash. M00 defined `BuildInputs` and the
store. M04 proves the hash reproduces on a cold rebuild in a fresh clone at
a different path, adds `reportHash`, completes the `hbf://` resources, and
builds the project graph that marks every item downstream of a changed
input as stale.

The parity target is the OGEE R16-P printed assembly: the interference
audit at its four poses with zero clashes, run by the registry on Part IR
and agreeing with the legacy oracle pair for pair.

```ts
const KERNEL_LANDS: Record<KernelId, string> = {
  geom: "M00", mesh: "M00", profile: "M00", "3mf": "M00", sim: "M02",
  inlay: "M03", circuit: "M05", motion: "M07", board: "M08",
};
const TARGET_LANDS: Partial<Record<TargetKind, string>> = { net: "M05", sheet: "M07", page: "M09" };

/** Returns the skip reason, or null when the check runs. */
export function skipReason(c: SkipInputs, kernels: ReadonlySet<KernelId>, targets: ReadonlySet<TargetKind>): string | null {
  const missing = c.needs.filter((k) => !kernels.has(k));
  if (missing.length > 0) {
    return `kernel ${missing.join(", ")} not registered (lands ${missing.map((k) => KERNEL_LANDS[k]).join(", ")})`;
  }
  if (!targets.has(c.target)) return `no ${c.target} targets yet (lands ${TARGET_LANDS[c.target] ?? "unknown"})`;
  if (c.pending !== null) return `run lands ${c.pending}`;
  return null;
}
```

   check returns one CheckResult with verdict `skip`, legal `{kind:
   "none"}`, the reason in `constraint`, and its origin URI. `pending`
   exists only for the R54 entries of M04-T12.

Steps:
1. `drivenBy(target, chase)` returns JSON pointers into the params. The
   default implementation `byConstraintDim(dim)` returns the pointers of
   every ParamField whose `constraintDim` equals the dim the check is

2. Nearest, in `packages/checks/src/nearest.ts`. An interval clamps and

   neighbours; a set returns the closest number; boolean and none have no

```ts
/** Clears float noise such as 3 x 0.4 = 1.2000000000000002. */
const tidy = (v: number): number => Math.round(v * 1e9) / 1e9;

/** Rounds toward the inside of the interval so the fix value is legal at the param's step. */
export function nearestInterval(lo: number, hi: number, measured: number, step: number): number {
  if (lo > hi) throw new Error("E_UNSAT reaches the solver, never this function");
  const k = (v: number) => Math.round(v / step);
  if (measured < lo) return tidy(Math.ceil(lo / step - 1e-9) * step);
  if (measured > hi) return tidy(Math.floor(hi / step + 1e-9) * step);
  return tidy(k(measured) * step);
}

export function nearestMultiple(base: number, measured: number): [number, number] {
  const n = measured / base;
  return [tidy(Math.floor(n + 1e-9) * base), tidy(Math.ceil(n - 1e-9) * base)];
}
```

2. Links are written when the thing is made: a build writes `reads` links

3. Stale rule: an item is stale when a link it depends on recorded a hash
   its target no longer has, or when an item it depends on is stale. The
   `because` list is the path of links to the changed item:

```ts
export function computeStale(items: readonly Item[], links: readonly Link[]): StaleEntry[] {
  const byId = new Map(items.map((i) => [i.id, i] as const));
  const out = new Map<string, string[]>();
  const deps = new Map<string, Link[]>();
  for (const l of links) deps.set(l.from, [...(deps.get(l.from) ?? []), l]);
  const visit = (id: string, seen: Set<string>): string[] | null => {
    if (out.has(id)) return out.get(id) ?? null;
    if (seen.has(id)) return null;
    seen.add(id);
    for (const l of deps.get(id) ?? []) {
      const to = byId.get(l.to);
      if (to === undefined || to.hash !== l.hashAtLink) {
        const path = [`${l.kind} ${l.to}`];
        out.set(id, path);
        return path;
      }
      const up = visit(l.to, seen);
      if (up !== null) {
        const path = [`${l.kind} ${l.to}`, ...up];
        out.set(id, path);
        return path;
      }
    }
    return null;
  };
  for (const i of items) visit(i.id, new Set());
  return [...out.entries()].map(([id, because]) => ({ id, because })).sort((a, b) => a.id.localeCompare(b.id));
}
```
