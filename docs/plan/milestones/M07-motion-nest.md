hbf (working name) is the binary with CLI, MCP and HTTP transports. CHASE

onward (D-010).

## What this milestone proves

Two tier 1 packages land here. `nest` turns parts into sheets and plates
and refuses to emit a cut file that a cutter would ruin. `motion` turns a
command into a program, a program into states, and a path into a planned
velocity profile, with one kinematics module that the build and the viewer
both import (D-139). Each piece is proven against the legacy design that
found its failure class.

| piece | legacy evidence | failure class it catches |
|---|---|---|
| sheet loop, shelf packer | SLUG `nest()` in `slug.html` | hand-placed sheets whose parts overlapped (BUILD.md) |
| MaxRects BSSF, auto gap | OGEE16 `plate_template.html` `packOne`, `autoGap` | plates packed by hand, parts on the skirt line |
| five sort orders | GUSSET `nest`, `nestOnce` | one sort order leaving a sheet that another order saves |
| connectivity refusal | OGEE16 `cutfiles.py` `check_connected` | a deck severed into five strips, a keeper cut in half |
| one DXF writer | every shipped emitter | outlines that reload open, files in metres, no version header |
| assembly-order mode | OGEE16 viewer `reg(..., asm)` steps; Roadkill (HPI) as prior art | a sheet that must be cut whole before the first assembly step |
| kinematics module | OGEE16 `kin.py` with its JS twin; DERRICK `arm_ref.json`; DAVIT `chain()` | a viewer placing a part by a route the CAD never used |
| programs | OGEE16 `sweep()` commit; SLUG vend | a latch decided by whichever frames rendered; vend drift |
| merged planners | DETENT `planSpeeds`; WASHER `planChainPen` | two planners with no shared interface or readout |

Four findings shape the cards. Every shipped emitter fails some part of
CHK-SHT-03, and three ship coordinates in millimetres under a metres
header because `ezdxf.new()` defaults `$INSUNITS` to 6. The legacy
oracles print and exit 0 (`check_viewer.py`, `kin.py`) or crash
(`audit_dxf.py` on POLYLINE), so their ports assert and exit non-zero
(D-153). SLUG's shipped sheets omit two acrylic panes and two return-cup
parts that exist as baked outlines. The latch identity seeded for
CHK-MOT-05 comes from OGEE R17b (`x/downloads/dl-ogee-stipple-mech/stipple/stipple (1).html`).
Its seeded form uses stroke/2 for the half select rise, which is exact on
STIPPLE's pin-free beam and off on R16. With the measured half rise it
holds on R16: (9.000 - 4.249) - 0.776 - 1.8 = 2.175 = 0.775 + 1.400.
