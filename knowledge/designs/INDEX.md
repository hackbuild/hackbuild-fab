# Originals: the sample set index

Written 2026-10-05; BUCK added 2026-10-06. This is the sample set a builder copies from: every design below is one of the owner's original benches, prints or boards, curated with its own record. The generated mockups at `fab-knowledge:mockups/` are quarantined and are not part of this set; nothing here cites or copies them.

The owner's originals are the bar. Every design is a full lit 3D bench or a real artifact (board, print, slicer save), and each record says how it was made so a new thing is made the same way. The cross index from every mechanism to these designs is `MECHANISMS.md` beside this file.

Where things are:

| what | path |
|---|---|
| originals root | `fab-knowledge:originals/` |
| record per design | `fab-knowledge:originals/<slug>/RECORD.md` |
| repo copy of each record | `knowledge/designs/<slug>.md` (byte identical) |
| canonical files and hashes | `fab-knowledge:originals/<slug>/files/` and `fab-knowledge:originals/<slug>/SHA256SUMS` |
| shots (viewed, taken from the original benches) | `fab-knowledge:originals/<slug>/shots/` |
| gold drives | `fab-knowledge:evidence/gold/` (pip-haft, toggle, blocks, collar-coin, cotter, tang-r6) |

Tiers used in the last column:

- gold: has a gold drive under fab-knowledge/evidence/gold; the owner's bar
- bar: a good original, drives clean; port from it
- bar for the generator; the shipped viewer throws on S.span, so port the generator and rebuild the viewer
- lineage: kept for its techniques and failure lessons; a newer original supersedes it or it is broken as shipped
- evidence: owner prints, slicer saves or printed artwork; read, never port as code

Count: 80 designs in 13 families (computed from this table, 2026-10-06; BUCK added to robots on 2026-10-06).

## Reading order for a builder

1. Pick the mechanism in `MECHANISMS.md`; it names the canonical design, file and function.
2. Open that design's record, section 5 (or 4) for the construction, then its UX section and its port map.
3. Open the gold drive shots of the gold designs to see the bar for the bench itself: a lit 3D model on the stage, a rail with steps, a drive pad, and exports that reproduce the shipped files.
4. Make the new thing in the same structure: a DOM-free kernel that builds from params, a shell that holds state and the commit model, and exports that a slicer opens.
