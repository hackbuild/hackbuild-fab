# Project records

Grouped by which kernel they exercise, because that is how they will be
retrieved. Each entry carries the honest numbers, what it taught, and what is
still open.

An open item here is CONTEXT, not an agenda. Several of these were last
touched months ago and may have been resolved since.

- `inlay-and-print.md` the flush-inlay art benches and printed cases
- `printed-circuits.md` conductive filament, printed sensors and instruments
- `copper-and-boards.md` vinyl-cut copper, PCBs and fab output
- `mechanisms.md` the pin display line, vending, mechanical logic
- `robots.md` arms, bipeds, tracked platforms, joints
- `devices.md` laser rigs, SDR, cameras, the live-instrument class
