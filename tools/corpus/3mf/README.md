# 3mf corpus

Fixtures the 3MF package is checked against (D-159).

| file | what | sha256 |
|---|---|---|
| `gold/hackbuild-coin-nfc.3mf` | conformance fixture one for M00: the slicer's own save of a three-filament coin, Flash Studio, zip entries dated 2026-08-19, 175450 bytes, BambuStudio-01.10.01.50 on Flashforge Creator 5 Pro 0.4 nozzle; copied unchanged from `fab-work-directory/benches/collar-coin/uploads/` | `24ee9c66419ac23eb2075e859bd0191a6431abb1d7d3628eea2372abc854f0c5` |
| `seed-97.json` | the seed's 97-key filament template (68 verbatim plus 29 computed), imported at M-1-T07 | |
| `template-diff.md` | generated by `tools/py/harvest_filament_template.py`: the gold per-filament keys against `seed-97.json` | |

`uv run --project tools/py tools/py/harvest_filament_template.py` writes
`packages/3mf/data/filament_template.json` and `template-diff.md` from the
gold file; `--check` fails when either drifts.

`inputs/` holds the writer agreement inputs that
`tools/py/test/test_agreement.py` builds with both writers.
`inputs/flex-pair-two.json` is generated: `npx tsc -b && node
tools/corpus/3mf/dump-input.mjs` writes it from the keys flex-pair build on
preset two as export3mf lays it out, and `--check` fails when it drifts.

`manifest.json` rows whose copy sits here say `where: "repo"`: gold,
known-bad and sprue, which tests read directly. The owner slicer saves
(`owner/`, `legacy/`, `boss/`, which hold the owner, cotter, round trip and
download rows) say `where: "private"` and sit under `HBF_CORPUS`, default
`fab-knowledge:originals/_corpus/`, at the same relative paths. Each copied
row records its sha256 and bytes. Without that folder `run.py` and
`packages/3mf/test/validate.test.ts` count the private rows as not run.
