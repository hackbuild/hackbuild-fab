how to slice this

Open the 3mf with File > Open Project. It should arrive as one object with a named part per colour and the extruders already set.

If a slicer strips the colours, load the three STLs together and answer yes to loading them as one object with multiple parts, then set the filament per part.

Ironing on for the top surface. No supports, no brim. Turn off arc fitting on the outer wall or the reeds get smoothed away.

Back face art is mirrored in the model on purpose. That face prints against the bed and is read from the other side once you flip the coin, so it looks backwards in a slicer bottom view and correct in your hand.

COLLAR.

A bench for designing 3D printed challenge coins. Everything it makes is a flat flush colour inlay, so nothing is embossed and both faces finish level. Four steps, left to right along the tabs.

  1. ArtSet how big the coin is, then drop a logo on each face or add text. A pipe in a text layer splits it into two colours: hack|.build.
  2. EdgeReeded, milled, knurled, beaded and the rest. This is the part that makes it read as a coin.
  3. ColourSay how many filaments you are using and what each one is. Art layers point at slot numbers, so you can decide the actual colours last.
  4. PrintLayer height, optional sealed pocket for an NFC tag, then export the 3mf.

The viewport rebuilds itself whenever you finish a change. Drag to orbit, scroll to zoom. The two panels under it are the faces as they read in your hand. Nothing is uploaded anywhere; this file does all of it locally.
